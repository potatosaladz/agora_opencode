# Ports and Adapters

**Version:** 1.4 · **Status:** design baseline — Phase 7 through T7-07 subset implemented
**Rule:** every external dependency is reached through a port. Domain and application
layers never import infrastructure SDKs. ADR:
[ADR-012](adr/ADR-012-clean-architecture-ports-adapters.md).

```text
backend/app/ports/          ← abstract contracts (typing.Protocol), this document
backend/app/adapters/       ← concrete implementations, swappable at composition time
backend/app/domain/         ← imports ports only
backend/app/application/    ← imports ports and domain
backend/app/composition/    ← the only place that imports adapters
```

## 0. Conventions for every port

| Concern | Requirement |
| --- | --- |
| Typing | `typing.Protocol`, `@runtime_checkable`, fully annotated, no `Any` in public signatures |
| Time | `datetime` arguments are UTC-aware; adapters must not read the clock implicitly |
| Ids | `uuidv7` strings generated by the caller, never by the adapter |
| Errors | port hierarchy `PortError` → `TransientPortError` / `PermanentPortError`; no raw driver exception escapes |
| Retries | adapters do **not** retry; the workflow layer owns retry policy |
| Timeouts | every method takes or carries a timeout; no unbounded waits |
| Idempotency | write methods accept `idempotency_key` where re-invocation is possible |
| Determinism | anything called from workflow code must be deterministic; nondeterminism lives in activities |
| Observability | every call emits a span with `session_id`, `correlation_id`, `code_version` |
| Secrets | never appear as arguments; only secret **references** cross a port boundary |
| Versioning | payload-carrying ports accept and return versioned contracts (`schema_version`) |

Concrete Temporal timeout, retry, heartbeat, operation-ID, dead-letter and checkpoint rules are normative
in [ORCHESTRATION_POLICY.md](ORCHESTRATION_POLICY.md). Port adapters translate dependency failures into
`TransientPortError` or `PermanentPortError`; Temporal classification happens only at the activity boundary.

## 1. `LLMProvider`

```python
@runtime_checkable
class LLMProvider(Protocol):
    async def generate(self, request: LLMRequest) -> LLMResponse: ...
    async def embed(self, inputs: Sequence[str], *, model: str) -> EmbeddingResponse: ...
    async def capabilities(self) -> ProviderCapabilities: ...
    async def health(self) -> HealthStatus: ...
```

`LLMRequest` carries `messages`, `response_schema` (Pydantic model → JSON Schema),
`temperature`, `max_output_tokens`, `stop`, `timeout_s`, `seed` (honoured only when
`capabilities().deterministic`), `trace: LLMCallTrace`, `secret_ref`.

`LLMResponse` carries `text`, `parsed: T | None`, `finish_reason`, `usage` (input, output,
embedding tokens, cost estimate), `model`, `provider`, `latency_ms`,
`raw_artifact_ref` (ObjectStore key), `retry_attempts`.

**Semantics**

- Structured output is validated against `response_schema` **inside the adapter**. A
  validation failure is `TransientPortError` (retryable) for a bounded number of repair
  attempts, then `PermanentPortError`.
- `generate` never mutates platform state and never decides workflow transitions.
- `raw_artifact_ref` is mandatory: exact request/response bytes are stored
  (secret-redacted) and referenced, so a call can be re-inspected years later.
- Adapters: `openai_compatible` (primary), `mock` (deterministic; tests and replay).

**Rejected alternatives:** provider SDKs used directly in domain code; LiteLLM as a hard
dependency (re-evaluate in Phase 2 — it may become an adapter, never a layer).

## 2. `WorkflowEngine`

```python
@runtime_checkable
class WorkflowEngine(Protocol):
    async def start(
        self, workflow_id: str, workflow_type: str, workflow_input: WorkflowInput,
        *, task_queue: str, timeout_s: float,
    ) -> WorkflowStart: ...
    async def describe(
        self, workflow_id: str, *, timeout_s: float,
    ) -> WorkflowExecution: ...
    async def signal(
        self, workflow_id: str, workflow_signal: WorkflowSignal, *, timeout_s: float,
    ) -> None: ...
    async def health(self) -> HealthStatus: ...
    async def close(self) -> None: ...

@runtime_checkable
class WorkflowWorker(Protocol):
    async def run(self) -> None: ...
    async def shutdown(self) -> None: ...
```

`WorkflowInput` is a strict, versioned JSON object; the public port contains no `Any`.
`workflow_id` is the start idempotency key. A duplicate start never creates another run:
`WorkflowStart.started` is `False` and the original `run_id` is returned. The Temporal adapter
pins `WorkflowIDReusePolicy.REJECT_DUPLICATE` and `WorkflowIDConflictPolicy.FAIL` rather than
depending on SDK defaults.

`WorkflowExecution.status` is **transport diagnostics only**. PostgreSQL `sessions.status` and
the append-only ledger are authoritative for domain/API state (ADR-001); callers must not infer a
session transition from Temporal visibility state.

Worker registration is intentionally not part of the client port. The separate `WorkflowWorker`
port owns lifecycle only; concrete workflow/activity definitions are immutable constructor inputs
to the Temporal worker adapter, supplied by the `workflow-worker` composition root in T4-02/T4-03.
T4-04 adds strict `WorkflowSignal` envelopes. Pause, resume, cancel and human directives use a typed
domain payload inside that envelope; the generic client port remains JSON-only and contains no
`Any`. Signal acceptance is not lifecycle authority: only workflow-interpreted transition activities
update PostgreSQL and append ledger events. Adapters: `temporal`, `inmemory` (offline tests).

## 3. `EventBus`

```python
@runtime_checkable
class EventBus(Protocol):
    async def publish(self, subject: str, event: ReasoningEvent) -> PublishAck: ...
    async def subscribe(self, subject: str, group: str, handler: EventHandler,
                        *, from_start: bool = False) -> Subscription: ...
    async def read_from(self, subject: str, sequence: int,
                        *, limit: int) -> Sequence[ReasoningEvent]: ...
    async def request(self, subject: str, message: Mapping[str, Any],
                      *, timeout_s: float) -> Mapping[str, Any]: ...
    async def health(self) -> HealthStatus: ...
```

**Semantics.** At-least-once delivery; consumers must be idempotent by `event_id`. The bus
is **transport only** — PostgreSQL holds the authoritative ledger
([ADR-004](adr/ADR-004-nats-event-transport.md),
[ADR-019](adr/ADR-019-append-only-event-ledger.md)). A publish failure never rolls back
committed state; a reconciliation job compares ledger sequence gaps against the stream.
Adapters: `nats_jetstream`, `inmemory`.

## 4. `RealtimeGateway`

## 5. `AgentRuntime` and `ReasoningStrategy`

```python
@runtime_checkable
class AgentRuntime(Protocol):
    async def run_turn(self, context: ReasoningContext) -> TurnExecutionResult[ProposalBundle]: ...

@runtime_checkable
class ReasoningStrategy(Protocol):
    name: str
    version: str
    async def propose(self, context: ReasoningContext) -> (
        ProposalBundle | TurnExecutionResult[ProposalBundle]
    ): ...
```

`ReasoningStrategy` is the pluggable *how an agent thinks* axis: chain-of-analysis,
devil's advocate, evidence-first, risk-first, role-conditioned. Strategies are versioned
and experiment-configurable. `AgentRuntime` composes a strategy, an `LLMProvider`, memory
references and an agent definition; it produces artifacts and never writes state. Critique responses
and position revision use the same `run_turn` operation with a typed phase/context rather than widening
the port for every protocol phase. Exact Phase 6 authority and evidence-disposition semantics are in
[PHASE6_ACCEPTANCE.md](PHASE6_ACCEPTANCE.md).

`TurnExecutionResult` preserves provider, model, input/output token counts, decimal USD cost and raw object
reference beside the typed proposal. Activity-backed strategies must provide the complete attribution tuple;
deterministic strategies return a proposal that the runtime normalizes to an explicit metadata-free,
zero-accounting result.

The coordinator assembles `ReasoningContext` fail closed from the durable session binding. The context
carries immutable snapshots of the exact definition/version, active typed objectives and constraints,
eligible prior artifact envelopes, and any authorized retrieval result with provenance. A successful
zero-match result retains its query and searched-namespace metadata; retrieval failure is raised rather
than represented as empty knowledge. Round-one `ASSESS` rejects visible artifacts before hydration.
These snapshots cross the activity boundary as deterministic JSON and are revalidated against durable
configuration before provider creation.

Coordinator commit uses narrow `AgentProposalStore` and `AgentProposalLedger` extensions over the existing
caller-transaction-scoped artifact and ledger ports. The store serializes one turn commit and exposes
locked artifact lookup; the ledger exposes exact event lookup. Adapters never allocate IDs or commit the
transaction. Complete exact retries are returned only after artifact content, graph-node identity and
ledger-event attribution all match; partial or conflicting prior state fails closed.

## 6. `ConsensusStrategy` and `ConvergenceStrategy`

```python
@runtime_checkable

    version: str
    def required_inputs(self) -> set[ArtifactType]: ...
    def parameters(self) -> Mapping[str, ParameterSpec]: ...
```

`ConsensusContext` is the full input set: alternatives, normalized propositions, agent

configuration and version. `ConsensusResult` must carry outcome, per-alternative scores,

(Phase 9); `deliberative`, `bayesian`, `prediction_market` (research track).

## 7. `SymbolicReasoner`

```python
@runtime_checkable
class SymbolicReasoner(Protocol):
    async def evaluate(self, model: FormalizationRevision) -> SymbolicReasoningResult: ...
```

Returns `SAT` / `UNSAT` / `UNKNOWN` — never a natural-language verdict. SAT carries symbol-sorted exact typed
witness values; UNSAT carries a contradiction-sufficient core identified by deterministic AGORA AST paths.
These values contain no solver SDK objects. `UNKNOWN` must be surfaced as unknown, never as satisfaction or violation. A rule
is enforceable only when `validation_status == VALIDATED`
([ADR-015](adr/ADR-015-z3-symbolic-reasoner.md)). Adapters: `z3`, `bracket`
(deterministic interval arithmetic, Phase 11), `datalog` (research track).

T11-03 persists immutable exact-revision evaluations through `SymbolicEvaluationRepository`, keyed by revision,
solver/version, and configuration. The repository is caller-transaction-owned and retries return the identical
evidence or fail on conflict. Natural-language violation verdicts and graph/outbox propagation remain later scope.
Invalid/unsupported input and solver failure are typed errors distinct from `UNSAT`; Z3 SDK values never
cross the port.

## 9. Retrieval and memory ports

```python
@runtime_checkable
class Retriever(Protocol):
    async def retrieve(self, request: RetrievalRequest) -> RetrievalResult: ...

@runtime_checkable
class Reranker(Protocol):
    async def rerank(self, query: str, candidates: Sequence[RetrievedChunk],
                     *, k: int) -> Sequence[RetrievedChunk]: ...

@runtime_checkable
class VectorStore(Protocol):
    async def upsert(self, namespace: str, items: Sequence[VectorItem]) -> None: ...
    async def query(self, namespace: str, vector: Sequence[float], *, k: int,
                    filters: Mapping[str, Any],
                    min_score: float) -> Sequence[VectorHit]: ...
    async def delete_namespace(self, namespace: str) -> int: ...

@runtime_checkable
class KnowledgeVectorIndex(Protocol):
    async def upsert(self, items: Sequence[KnowledgeEmbedding]) -> None: ...
    async def query(self, namespace_id: UUID, vector: Sequence[float], *,
                    embedding_model: str, embedding_version: str, k: int,
                    min_score: float) -> Sequence[KnowledgeVectorHit]: ...
    async def delete_namespace(self, namespace_id: UUID) -> int: ...

@runtime_checkable
class MemoryProvider(Protocol):
    async def read(self, scope: MemoryScope, query: MemoryQuery) -> MemoryResult: ...
    async def write(self, scope: MemoryScope, entry: MemoryEntry) -> MemoryRef: ...
    async def promote(self, source: ArtifactRef, target: MemoryScope,
                      validation: ValidationRecord) -> MemoryRef: ...
    async def expire(self, scope: MemoryScope, policy: RetentionPolicy) -> int: ...
```

T5-08 binds this frozen port to `SqlAlchemyMemoryProvider`. Working state remains Redis TTL state,
episodic state remains reasoning ledger/session artifacts, and procedural state remains immutable agent
configuration; only semantic state uses promotion tables. Direct semantic `write` fails. `promote`
accepts an explicit semantic scope and persists a source-artifact snapshot, active human validator,
non-empty active evidence set, non-empty caveats, optional review date and supersession history. `read`
derives state as of the requested time; a passed `review_by` yields `STALE`. `expire` appends `STALE` or
`ARCHIVED`; it never updates or deletes authoritative entry/promotion rows.

`RetrievalRequest` includes stable `attempt_id` and `trace_id`, explicit `principal_class` (`HUMAN | AGENT`),
`principal_id`, typed subjects and a non-empty namespace set; missing scope is **rejected**, never defaulted
to "all". Request subjects express intent only. PostgreSQL validates workspace membership, agent-definition
identity, namespace manifests, session context and `session_agents` binding before resolving grants and chunk
ACLs before either lexical or vector scoring. `RetrievalResult` records query
hash, requested/searched namespace refs, index and embedding versions, arm counts, degradation state
and ordered `RetrievedChunk` values. Each `RetrievedChunk` carries exact source/document/chunk IDs,
source and chunk hashes, locator/span, source/retrieval timestamps, trust, lexical/vector/fused/rerank
scores and index version. Text is untrusted candidate data, never evidence by itself.

`RetrievalAudit.append(RetrievalAttempt)` is mandatory for retrieval composition. Denied attempts are
appended before the denial is raised; allowed attempts are appended after result assembly and before return.
Audit failure fails retrieval closed. Attempts carry hashes, IDs, counts, outcome and degradation metadata,
never query or chunk text.

`CitationRepository.attach_manual(ManualEvidenceCitation)` resolves the human workspace membership,
`EVIDENCE` owner/provenance, target claim, namespace/source/document/chunk chain, locator span, hashes,
timestamps and trust against PostgreSQL before appending an immutable dependency snapshot.
`resolve` preserves that snapshot after retraction while exposing current source state. `retract_source`
is one-way, requires a nonblank human reason, appends a durable fact and returns dependent evidence and
claim IDs for Phase 10 impact traversal. Citation and retraction operations share the caller transaction.

`VectorHit` remains the lower-level adapter result and carries `chunk_id`, `document_id`, `source_id`,
`content_hash`, `score`, `metadata`. Authorization belongs above this adapter but its query receives
only already-authorized namespace/filter arms; no adapter API offers an all-namespace query.
`KnowledgeVectorIndex` is the typed Phase 5 extension over the same `vector_items` adapter. Its writes
carry UUID provenance and pinned model/version, are accepted only when the full PostgreSQL chain and
content hash resolve, and its reads reject a namespace index built under another embedding identity.
`MemoryProvider.write` rejects semantic scopes. Semantic memory is reachable only through `promote`
with an explicit validation record; raw transcripts and model output never become knowledge
([MEMORY_ARCHITECTURE.md](MEMORY_ARCHITECTURE.md)).

```python
class ObjectStore(Protocol):

class SecretProvider(Protocol):

    async def store(self, ref: SecretRef, value: str) -> None: ...
    def redact(self, text: str) -> str: ...

@runtime_checkable
class SandboxExecutionProvider(Protocol):
    async def execute(self, request: SandboxRequest) -> SandboxResult: ...

class WorkspaceRole(StrEnum):
    ADMIN = "ADMIN"
    RESEARCHER = "RESEARCHER"
    OPERATOR = "OPERATOR"
    VIEWER = "VIEWER"

@dataclass(frozen=True)
class VerifiedPrincipal:
    subject: str
    user_id: UUID
    workspace_id: UUID
    role: WorkspaceRole

@runtime_checkable
class AccessTokenVerifier(Protocol):
    async def verify(self, token: str) -> VerifiedPrincipal: ...
```

`AccessTokenVerifier` validates token signature, issuer, audience, and expiry, then resolves an active
workspace membership from trusted state. It never accepts a client-supplied role or workspace without
that resolution. Verification failure raises `AccessTokenVerificationError`. Phase 1 composes
`UnconfiguredAccessTokenVerifier`, which rejects every token until an external IdP adapter is supplied;
the platform never signs local bearer tokens.

`SandboxRequest`: image **digest** (never a floating tag), entrypoint, args, input artifact
refs, cpu/mem/disk/pids limits, wall-clock timeout, network policy (`NONE` by default),
filesystem policy (read-only root plus one writable tmpfs). `SandboxResult`: exit code,
stdout/stderr artifact refs, resource usage, `terminated_by`. The broker is the only
component permitted to create containers
([ADR-018](adr/ADR-018-sandbox-execution-boundary.md)).

## 13. `ReasoningGraphStore`

```python
@runtime_checkable
class ReasoningGraphWriter(Protocol):
    async def add_node(self, node: GraphNode) -> None: ...
    async def add_edge(self, edge: GraphEdge) -> None: ...
    async def node_for_artifact(self, workspace_id: UUID, session_id: UUID,
                                artifact_id: UUID) -> GraphNode | None: ...

@runtime_checkable
class ReasoningGraphStore(ReasoningGraphWriter, Protocol):
    async def trace_backward(self, workspace_id: UUID, session_id: UUID,
                             node_id: UUID, *, max_depth: int = 12,
                             edge_types: frozenset[GraphEdgeType] | None = None,
                             page_size: int = 100,
                             cursor: str | None = None) -> TraversalResult: ...
    async def trace_forward(self, workspace_id: UUID, session_id: UUID,
                            node_id: UUID, *, max_depth: int = 12,
                            edge_types: frozenset[GraphEdgeType] | None = None,
                            page_size: int = 100,
                            cursor: str | None = None) -> TraversalResult: ...
    async def subgraph(self, workspace_id: UUID, session_id: UUID,
                       root_ids: tuple[UUID, ...], *, max_depth: int = 2,
                       edge_types: frozenset[GraphEdgeType] | None = None,
                       page_size: int = 100,
                       cursor: str | None = None) -> TraversalResult: ...
```

Adapter: `postgres` (recursive CTEs over `graph_nodes` / `graph_edges`). Neo4j, Memgraph
and RDF stores are future adapters; the port shape must stay graph-database-neutral
([ADR-007](adr/ADR-007-postgres-reasoning-graph.md)).

Phase 3 implemented atomic projection writes and the tenant/session-scoped `node_for_artifact`
lookup. Phase 10 adds tenant/session-scoped backward, forward, and bidirectional traversals with
bounded depth, edge filters, cycle safety, deterministic opaque cursor pagination, and independent
`truncated` and `next_cursor` result signals. T10-04 composes `trace_forward` across all citation roots,
sessions, cursors, and bounded depth segments; it does not introduce a second traversal engine.

`ProvenanceService.provenance_of` composes `ReasoningGraphStore.trace_backward`, the canonical artifact
store, and `CitationRepository.citations_for_evidence`. The citation method returns a deterministic
collection because the schema permits multiple distinct chunks per evidence artifact. Each item is a
`CitationResolution`, preserving the attachment-time source/document/chunk snapshot while exposing the
current source status and optional retraction metadata. Application code never queries citation tables
directly.

## 16. Adding a port or adapter

1. Write the protocol in `app/ports/<name>.py` with docstrings for semantics, failure
   modes and idempotency.
2. Add a contract test suite in `tests/contracts/` that **every** adapter must pass.
3. Implement the adapter; register it in the composition root behind configuration.
4. Provide a deterministic `mock` or `inmemory` adapter so tests never need the real
   dependency.
5. Document it here and in [EXTENDING.md](EXTENDING.md).
6. If the port changes externally visible payloads, update
   [API_CONTRACTS.md](API_CONTRACTS.md) and
   [../memory-bank/api-contracts.md](../memory-bank/api-contracts.md) in the same commit.
